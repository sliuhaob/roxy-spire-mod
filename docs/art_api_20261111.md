# API 美术补全

2026-11-11。使用 OpenAI 图像 API 生成 14 张原图：gpt-image-2.6-sunburst，medium 质量，透明背景。这些图片与此前的卡图一样由 AI 生成。

先用 gpt-image-1.5 生成过一版（gpt-image-2 不支持透明背景）。随后以教鞭为样本对比 gpt-image-2.5 与 2.6 的 flare、sunburst 四个版本：四者都支持透明背景，线条和轮廓都优于 1.5，其中 2.6-sunburst 的轮廓最粗、成品感最强，缩小到游戏尺寸后依然清楚，因此全部 14 张改用它重新生成。1.5 版未提交。

## 替换范围

- 9 件遗物（起始遗物除外）：原为扁平矢量图形，改为手绘风格，画法与配色参照起始遗物“洛琪希的魔力结晶”。每件导出 128 图标、256 大图和 128 轮廓。初级咏唱讲义页面上的符文曾被画成近似真实文字或宗教符号，已改为提示词限定的自创几何符文。
- 起始遗物的轮廓图原为全透明，悬停和闪光时没有外框。按原版做法，由图标外形外扩 3 像素重建为白色轮廓。
- 3 个状态图标：接续、枯竭、冰冻。原为程序绘制，改为与其余状态图标一致的绘制风格。枯竭用紫灰色表示负面状态，冰冻用冰白色，与水系图标区分。旧的两个绘制脚本已删除。
- 战斗能量球：原为原版铁甲战士的红色能量球。改为静止外框加旋转水涡，能量为 0 时变灰并减速。获得能量时的闪光沿用原版蓝色。

## 原图与重现

原图、每张图的完整提示词和请求参数（同名 .json）位于：

- art_sources/relics/api_20261111
- art_sources/powers/api_20261111
- art_sources/ui/energy_orb_20261111

各目录的 manifest.json 记录共用风格描述和每张图的主题。

```powershell
$env:OPENAI_API_KEY = '<你的密钥>'
python art_sources/tools/generate_batch.py art_sources/relics/api_20261111/manifest.json
python art_sources/tools/export_relics.py
python art_sources/tools/export_powers.py
python art_sources/tools/export_energy_orb.py
```

已存在的原图会跳过，用 --only 名称重做指定图片。密钥只从环境变量读取，不写入任何文件。导出脚本只做裁切、缩放、轮廓与图层拆分。需要 Python 3、Pillow 和 requests。

## 修复

洛琪希的魔力晶核（Boss 遗物）替换起始遗物时，先移除起始遗物再写回原位置，导致紧随其后的遗物被覆盖丢失。现改为与原版一致的原位替换。冒烟测试一次获得全部遗物时发现了这个问题。
