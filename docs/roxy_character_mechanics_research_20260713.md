## 二、人物特质提取

### 1. 她是努力型的水系魔术师，不是无条件的天才炮台

官方资料将洛琪希定位为米格路德族的水圣级魔术师和鲁迪的师傅。萌娘百科进一步概括她为水王级、A级冒险者，并强调她礼貌、勤奋，擅长水系魔术和缩略咏唱。社区人物资料也反复提到她会分析情报、不断学习，并在经历挫折后变得更谦逊。

可提取的设计关键词：`勤奋`、`准备`、`精确施法`、`高阶术式需要代价`。

不适合的表现：每回合天然获得大量能量，然后无条件连续释放高阶法术。那更像拥有异常庞大魔力的鲁迪，而不是依靠知识、经验和法杖弥补限制的洛琪希。

### 2. 她擅长的是缩略咏唱，而非稳定的无咏唱

萌娘百科记载她能缩略咏唱，从而把上级魔术投入实战；同一条目又记载她看到鲁迪以无咏唱释放魔术时十分震惊。这两点应同时保留：洛琪希的强项是把完整术式压缩到实战可用，而不是彻底取消施法过程。

可提取的设计关键词：`短咏唱`、`术式顺序`、`准备后减耗`、`以技巧替代蛮力`。

对当前 Mod 的影响：`无吟唱水魔法`、`零式咏唱`如果作为少数稀有牌，可以解释为超常发挥或术式模拟；如果成为全角色的常规能力，就会偏离角色原设。更贴合的名称可以是“极短咏唱”“术式省略”或“瞬时演算”。

### 3. 水、冰、雨与雷不是四条孤立元素，而是水系术式的派生

萌娘百科把她的主要战斗方式概括为“围绕水系魔术衍生的混合魔术”，列出的代表术式包括冰霜新星、冰枪、豪雷积雨云和雷光。换句话说，冰冻和雷击最好表现为水经过相变、凝聚或压缩后的结果，而不是互不相干的卡牌标签。

可提取的设计关键词：`水相变化`、`湿润后冰结`、`积雨后落雷`、`范围水术压缩为单点雷击`。

### 4. 她缺失念话，因此主动学习语言、魔术并离开故乡

官方出版方对外传的简介都把“族人能用念话交流，而洛琪希不能”放在她人生起点：她在沉默和孤独中长大，后来因为接触魔术而看见更广阔的世界，并离乡求学。这个设定比发色、身高或甜食偏好更接近人物内核。

可提取的设计关键词：`用可学习的术式取代天生能力`、`有顺序的言语施法`、`独立成长`、`跨越沟通障碍`。

设计注意：不建议把“缺失念话”直接做成沉默、禁用卡牌或永久负面状态。那会把人物经历简化成惩罚。更好的转译是让玩家通过学习和排列“术句”获得优势。

### 5. 她既是教师，也是一直在学习的人

官方动画第 2 集把她的教学和毕业考试作为核心；角色资料则显示她后来仍持续学习、任教。她不是只给别人加 Buff 的“辅助型老师”，而是会备课、示范、纠错，也会承认不足并继续钻研的教师。

可提取的设计关键词：`讲解与示范`、`复习`、`纠错`、`毕业考试`、`重复练习后掌握`。

### 6. 她有真正的冒险者与迷宫实战经验

萌娘百科称她为 A 级冒险者，并强调她有近距离对人、对魔物战斗经验；外传官方简介也把离乡、组队、旅行和试炼作为主要经历。她不应只是站在远处蓄力的脆弱法师。

可提取的设计关键词：`勘察`、`应变`、`短距离施法`、`面对未知仍能修正计划`。

### 7. 法杖是增幅器，魔力极限是真实限制

社区能力资料称，她的法杖由适合水魔术的材料和魔石制成，会显著增强水系法术；同一资料也把法杖的来历与她自身魔力量不足联系起来。具体“水系接近两倍、火系减半”等倍率尚未在本次官方页面中核实，不宜原样做成游戏数值，但“依靠专用法杖放大擅长属性、弥补魔力上限”这一方向很适合设计。

可提取的设计关键词：`法杖调律`、`专精水系`、`高阶术式后的枯竭`、`装备弥补天赋上限`。

### 8. 冷静、理性与偶尔冒失可以同时存在

官方声优寄语直接提到她“略有冒失”；社区人物资料则强调她通常冷静、善于推理。最贴合的玩法不是纯随机“犯错”，而是让部分牌在条件未满足时效果较弱，同时允许玩家通过“修正”把损失控制住。

可提取的设计关键词：`条件施法`、`失败时保底`、`临场修正`。

## 三、适合洛琪希的机制候选

以下机制都以“不新增整套卡牌，只改造现有重复卡”为前提。每个机制都给出人物依据、规则草案和风险。

### 机制 A：术句——起式与结式

**人物依据：** 缺失念话，却依靠语言和学习掌握魔术；擅长缩略咏唱而非真正无咏唱。

**规则草案：**

- 部分准备型技能具有关键词“起式”。打出后获得 1 个不可叠加的“接续”。
- 部分攻击或高阶技能具有关键词“结式”。打出时消耗“接续”，触发牌面上标明的额外效果。
- “接续”在回合结束时消失，不能长期囤积。
- 起式和结式只覆盖约 15-20 张核心牌，不给全部卡强行加标签。

**卡牌示例：**

| 现有牌 | 可改方向 |
| --- | --- |
| 初级咏唱 | 起式；获得咏唱并建立接续 |
| 水幕 | 起式；获得格挡，若已有接续则不重复叠加 |
| 冰霜新星 | 结式；接续时少消耗 1 层咏唱 |
| 圣级水枪 | 结式；接续时提高伤害或获得穿透格挡式奖励 |
| 雷光/王级水魔法 | 结式；只有在接续时获得完整强化，否则进入枯竭 |

**优点：** 不需要再增加可无限累积的资源；打牌顺序会明显区别于原版角色；“先说起句、再完成术式”的手感很贴人物。

**风险：** 如果所有结式都只是“加伤害”，机制会变成简单连击。奖励应分成减耗、控制、防御和范围四类。

**推荐度：最高。** 它比“无吟唱窗口”更准确地表现洛琪希，也可以与现有咏唱资源共存。

### 机制 B：水相——湿润、冰结与雷击

**人物依据：** 她的冰、雨和雷是围绕水系魔术发展出的混合术式。

**规则草案：**

- 部分基础水术施加敌方状态“湿润”，建议上限 3 层；敌人回合结束时减少 1 层。
- 对湿润目标施加冰冻时，消耗 1 层湿润并额外施加 1 层冰冻。
- 雷系牌消耗目标全部湿润，每层增加固定伤害；大型雷术可以把部分伤害扩散给其他敌人。
- 冰冻负责控制，雷击负责兑现，玩家必须选择湿润层数的用途。

**卡牌示例：**

| 现有牌 | 可改方向 |
| --- | --- |
| 水弹术、凝水一击 | 少量湿润的稳定来源 |
| 水鞭、连珠水弹 | 对湿润目标得到战术奖励，而不是单纯再抽牌 |
| 小冰锥、冰霜新星 | 消耗湿润强化冰冻 |
| 积雨云 | 每回合随机铺湿润，为后续冰或雷做准备 |
| 王级水魔法 | 重新定位为压缩后的雷击终结牌 |

**优点：** 把现有的水、冰、雨、雷统一成一套因果关系；冰冻不再只是孤立 Debuff；玩家有控制与伤害之间的明确选择。

**风险：** 会新增一个敌方状态，必须删掉一部分现有的虚弱、抽牌和泛用增伤文字，避免卡面过长。冰冻跳过回合本身很强，因此湿润转冰冻只能一次多 1 层，不能按全部湿润翻倍。

**推荐度：高。** 适合作为第二主轴，但应在冰冻机制稳定后再做。

### 机制 C：极限施法——允许强行释放，但承担枯竭

**人物依据：** 洛琪希能施放高阶水术，但魔力量并非无限；雷光等高阶术式会造成明显消耗，专用法杖的存在也说明她需要用技术和装备弥补上限。

**规则草案：**

- 圣级、王级牌标注“需求 X 层咏唱”。
- 咏唱足够时，正常消耗并完整施放。
- 咏唱不足时仍可打出，但每缺 1 层获得 1 层“枯竭”。
- 下回合开始，每层枯竭使能量减少 1，随后清除；建议枯竭最多 2 层。
- 法杖类遗物或能力牌负责减少一次枯竭，而不是继续无条件加能量。

**优点：** 不把不满足条件的高阶牌变成死牌，同时把“提前爆发还是充分准备”变成真正决策；还能反向约束当前初始遗物带来的高能量基线。

**风险：** 不能让玩家因能量降到 0 而连续两回合无法行动；需设置层数上限，并检查与能量遗物的结算顺序。

**推荐度：高。** 只需用于 4-6 张高阶牌，不应扩散到普通卡。

### 机制 D：复习——第二次使用同一术式才体现掌握

**人物依据：** 教师、优等生、持续研究和纠错；她的强大来自反复学习，而不是一次看见就永久掌握。

**规则草案：**

- 带“复习”文字的卡牌记录本场战斗是否已经打出过同名牌。
- 第一次打出为“讲解”，只执行基础效果。
- 本场第二次及以后打出同名牌时，触发牌面上的复习奖励。
- 记录按 card ID 而不是单张卡 UUID 计算，因此两张同名牌可以互相完成复习。

**卡牌示例：** 魔术讲义复习时额外获得咏唱；水弹术复习时增加伤害；术式修正复习时升级另一张手牌；课堂书签负责把一张牌送回抽牌堆以便复习。

**优点：** 能自然利用现有回收、抽牌和重复施法卡，教学线终于有独立节奏；也能让拿第二张同名牌成为构筑选择。

**风险：** 与回声授课、再咏唱等复制或回收效果组合时可能增长过快。复习奖励应是一次小强化，不能反复产生能量和抽牌。

**推荐度：中高。** 适合覆盖 8-12 张教学/研习牌，不做全角色规则。

### 机制 E：勘察——用预判替代过量抽牌

**人物依据：** A 级冒险者、迷宫经历、冷静分析和近距离实战经验。

**规则草案：**

- “勘察 X”：查看抽牌堆顶 X 张牌，选择 1 张留在牌堆顶，其余放入弃牌堆。
- 少数高阶勘察牌可以把 1 张选中的牌放入手牌，但不应成为常态。
- 将迷宫洞察、迷宫地图、安静研读、备课等直接抽牌效果中的一部分改为勘察。

**优点：** 当前卡池有约 30 张抽牌相关牌，勘察可以直接减少同质抽牌，同时表现经验和预判；技术实现也比新建复杂资源简单。

**风险：** 它与原版观者的“预见”接近，因此应强调“留 1 张在顶端”的路线规划，而不是完全照搬“任意弃置”。

**推荐度：中。** 很适合做辅助机制，但不足以单独成为角色主轴。

### 机制 F：临场修正——条件失败时保住下限

**人物依据：** 平时冷静有经验，意外和紧张时偶尔冒失，但会反思并纠正。

**规则草案：**

- 少数条件牌同时写明“修正：若条件未满足，改为获得 2 点格挡或 1 层咏唱”。
- 每张牌只保留一种很小的保底，不设置新的可叠加状态。
- 例如河流推击在目标没有冰冻时不抽牌，但触发修正获得少量格挡；精准施法条件失败时获得 1 层咏唱而不是完整收益。

**优点：** 条件构筑不容易拿到死牌，人物的“冒失但能补救”也得到体现。

**风险：** 保底过高会让玩家无视条件。修正收益必须显著低于成功收益。

**推荐度：中低。** 作为 3-5 张牌的共同写法即可，不要做成主资源。

## 四、不建议作为核心战斗机制的特质

| 特质 | 原因 | 更适合的载体 |
| --- | --- | --- |
| 外表年幼、实际成年 | 是视觉和身份信息，硬做成战斗数值容易失真 | 角色立绘、选择界面和文本 |
| 喜欢甜食 | 有趣但不足以支撑完整卡组 | 药水、事件或商店遗物 |
| 冒失 | 做成大量随机失败会削弱玩家控制感 | 少量“临场修正”牌和事件文本 |
| “女神”梗、贤者时间等粉丝梗 | 更接近鲁迪或观众视角，不是洛琪希本人的主要战斗能力 | 彩蛋牌、遗物或可选模式，不宜占据主机制中心 |
| 缺失念话 | 直接做成沉默或禁用会把成长经历等同于惩罚 | 转化为“术句”“学习语言与术式”的正向机制 |

当前“贤者时间”的数值效果可以保留为稀有短时爆发，但若目标是严肃还原人物，建议以后改名为“高度集中”“瞬时演算”或“术式通明”。

## 五、推荐的最终机制组合

### 首选方案：短咏唱术师

1. 保留现有“咏唱”，但削减它在卡池中的覆盖率。
2. 新增“术句：起式/结式”，负责主要打牌顺序。
3. 只给高阶术式加入“极限施法/枯竭”，约束提前爆发。
4. 教学牌少量使用“复习”，作为第三层构筑方向。

这套组合最贴近“努力型、短咏唱、教师、魔力有限但经验丰富”的洛琪希，而且不需要再新增一个可以无限堆叠的主资源。

### 次选方案：水相控制术师

1. 保留现有咏唱作为高阶术式燃料。
2. 新增湿润，让水术在冰冻控制和雷击伤害之间分流。
3. 使用勘察代替部分直接抽牌，表现冒险者经验。
4. 极限施法只用于雷光、豪雷积雨云等少数终结牌。

这套组合战斗辨识度更强，但会同时涉及湿润、冰冻和咏唱三个状态，界面与说明压力更大，应晚于首选方案开发。

## 六、与当前 Mod 的具体衔接建议

优先级从高到低：

1. 把角色设定基准从“无咏唱法师”改为“擅长缩略咏唱的水系术师”。先改策划口径，暂不急着改所有牌名。
2. 选择“术句”作为下一项试验机制，只改 6 张牌：3 张起式、3 张结式；实机稳定后再扩大。
3. 把 `无吟唱水魔法` 的表现解释为极短咏唱或超常集中；把“贤者时间”视为开发期名称，正式版再决定是否改名。
4. 用“极限施法”改造 2 张高阶牌，优先测试王级水魔法和大瀑布；暂时不要同时修改全部稀有牌。
5. 等冰冻实机稳定后，再考虑湿润的水相反应。第一版只允许“湿润 + 冰冻”，雷击兑现放到下一批。
6. 教学线先用 3 张牌测试复习，不要与术式记录、指导、课题等多个相近系统并存。

## 七、第一轮原型建议

最小可测试原型只需要 8 张牌和 1 个状态：

| 类型 | 牌 | 原型任务 |
| --- | --- | --- |
| 起式 | 初级咏唱 | 建立接续并获得咏唱 |
| 起式 | 水幕 | 防御型起式 |
| 起式 | 安静研读 | 牌序型起式，减少直接抽牌 |
| 结式 | 冰霜新星 | 接续时降低咏唱消耗 |
| 结式 | 圣级水枪 | 接续时获得单体强化 |
| 结式 | 洪流壁 | 接续时获得防御强化 |
| 极限施法 | 王级水魔法 | 咏唱不足时获得枯竭 |
| 复习 | 魔术讲义 | 第二次打出时获得小额额外收益 |
| 状态 | 接续 | 不叠加，回合结束消失 |

这一原型足以回答三个关键问题：术句是否有趣、与现有咏唱是否重复、以及高阶牌允许强行释放是否比“条件不足不能用”更自然。通过后再决定是否加入湿润。

## 八、结论

从人物设定出发，洛琪希最有辨识度的不是“蓝色水法师”或“每回合多一点能量”，而是以下组合：

- 因为无法依靠族人的念话，她通过语言、学习和术式建立自己的道路。
- 她擅长把咏唱缩短到实战可用，但高阶魔法仍然需要准备和代价。
- 她把水发展为冰、雨和雷，并通过法杖与知识弥补魔力上限。
- 她既会教学，也会复习、纠错和继续成长。
- 她有冒险者的预判与近距离应变，不是只能站桩蓄力的炮台。

因此最推荐的机制顺序是：`术句` > `极限施法` > `复习` > `水相` > `勘察`。其中术句和极限施法最值得优先原型化；水相很有潜力，但应等冰冻和当前卡池完成第一轮收束后再加入。
