# 洛琪希对标原版角色差距规划

更新时间：2026-07-09

## 当前结论

洛琪希现在已经从“能进游戏的测试角色”进入“卡池已成型但还不像正式原版角色”的阶段。当前最大差距不是卡牌数量，而是文本系统、关键词系统、遗物和药水生态、解锁流程、平衡验证、稳定性测试、视觉统一度和发布清理。

## 当前状态快照

| 模块 | 当前状态 | 对标原版差距 |
| --- | --- | --- |
| 角色框架 | 已有自定义角色、初始牌组、初始遗物、角色选择图、局内图、火堆图 | 角色文本仍硬编码，事件文字不完整，火堆/局内视觉还要继续对齐原版视角 |
| 卡牌数量 | 已有 75 张卡牌 Java 类 | 数量够了，但稀有度当前为 BASIC 4 / COMMON 19 / UNCOMMON 36 / RARE 16，需要重新审视分布 |
| 卡牌图片 | 75 张卡图 + 75 张大图均存在 | 风格仍需统一检查，部分图可能只是占位或简笔图 |
| 卡牌文本 | 75 张卡牌均已使用 `CardStrings` | 已完成原版式卡牌文本迁移，后续只需继续校对文本质量 |
| 关键词 | 已注册 `咏唱`、`贤者时间` | 需进游戏确认百科、卡面高亮和 tooltip 显示是否完全正常 |
| 能力状态 | 已有咏唱、贤者时间及多种自定义 Power | Power 名称和描述仍硬编码，没有 `PowerStrings`；图标尺寸和说明需要统一 |
| 遗物 | 已有 10 个专属遗物，含初始遗物和 Boss 替换遗物 | 仍缺游戏内掉落、替换流程和完整平衡审查 |
| 药水 | 已有 3 个洛琪希专属药水 | 需要进游戏确认掉落、商店、百科和 tooltip 正常 |
| 解锁 | 开发期强制全部卡牌在百科可见 | 正式版必须移除此开发辅助功能，是否做正式解锁路线待定 |
| 稳定性 | 能编译和安装，已修过若干崩溃 | 还缺少完整跑图回归：战斗、奖励、宝箱、商店、火堆、Boss、保存读取 |
| 发布标识 | 包名和 Mod ID 仍是 `startermod` | 正式版应统一成 Roxy 相关命名，避免看起来像模板工程 |

## 对标原版需要补齐的内容

### 1. 原版式文本与关键词系统

目标：所有卡牌、能力、遗物、角色描述都从语言包读取，卡面关键词按原版中文格式显示。

任务：

| 优先级 | 任务 | 状态 |
| --- | --- | --- |
| P0 | 把 75 张卡的 `NAME` / `DESCRIPTION` / `UPGRADE_DESCRIPTION` 迁入 `CardStrings.json` | 已完成，75/75 |
| P0 | 把 `咏唱`、`贤者时间` 注册为正式关键词，并精简右侧说明 | 已完成，待游戏内确认 |
| P0 | 所有中文描述改成原版格式，例如 `获得 !M! 层 咏唱 。` | 已完成，待游戏内校对 |
| P1 | 把 Power 名称和描述迁入 `PowerStrings.json` | 待做 |
| P1 | 把角色选择界面文字迁入 `CharacterStrings` 或统一文本常量 | 待做 |

### 3. 洛琪希核心机制

目标：让洛琪希有像原版四角色一样鲜明且稳定的核心机制。

当前核心：

- `咏唱`：资源积累、触发额外效果、部分卡会消耗。
- `贤者时间`：获得格挡、造成攻击伤害、获得咏唱时追加数值，并逐回合衰减。
- 水魔法：直接伤害、多段伤害、消耗咏唱爆发。
- 教师/研习：抽牌、升级、费用调整。
- 结界防御：格挡、虚弱、反击、减伤。

任务：

| 优先级 | 任务 | 状态 |
| --- | --- | --- |
| P0 | 明确咏唱是否是“资源层数”、是否每回合保留、是否有上限 | 需要文档固定 |
| P0 | 检查贤者时间是否会造成递归、重复触发或文本误导 | 需要测试 |
| P1 | 给 `咏唱` 和 `贤者时间` 分别做标准 Power 图标 | 待做 |
| P1 | 明确每个流派的普通/罕见/稀有核心牌 | 待做 |
| P2 | 设计少量反向约束，避免只堆咏唱变成无脑最优 | 待做 |
